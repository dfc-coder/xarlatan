# v0.5.0-beta.1 release candidate

This candidate is the first Phase 2 beta intended for physical continuous-voice testing.

It includes continuous capture, Silero VAD, bounded pre-roll, transcript wake gating, bounded partial/final STT events, sentence-level LLM-to-TTS streaming, persistent playback, TurnID-scoped cancellation, and conservative wake-qualified physical barge-in.

The release remains pre-physical until the acceptance report produced on `dakota-fedora` ends exactly with `Final result: PASS`.
